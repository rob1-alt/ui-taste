Agents build the same interface every time. A purple gradient hero, three centred cards with emoji icons, Inter everywhere, shadows on everything. UI taste replaces that default with evidence.

How it works

Four steps, every time Claude touches an interface.

  1. 01

    Inspect

    Read the project's own design system first: DESIGN.md, tokens, Tailwind config, components. The project always wins over a reference.

  2. 02

    Reference

    Search the library only for a concrete decision. One strong screen is enough, three is the limit, and Claude opens the screenshot before deciding.

  3. 03

    Build

    Apply the decision with the project's components: one type family, a real scale, neutral surfaces and one accent, real content only.

  4. 04

    Review

    Render the screen at 1440px and 390px, look at it, and go through the anti-slop checklist. A UI that was never looked at is not reviewed.
