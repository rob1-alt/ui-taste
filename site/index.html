    How Claude uses it

    Four steps, every time it builds or reviews an interface.

    1. 1

      Inspect

      Read the project's own system first: a DESIGN.md, the tokens, the Tailwind config, the components. The project wins over any reference.

    2. 2

      Reference

      Search the library only to settle a concrete question. One strong screen is enough, three is the limit, and Claude opens the screenshot before it decides.

    3. 3

      Build

      Apply the decision with the project's components: one type family, a real scale, neutral surfaces and one accent, real content only.

    4. 4

      Review

      Render at 1440 and 390 pixels, look at it, and go through the checklist below. A screen that was never looked at is not reviewed.

    The review

    Install

    Two commands in Claude Code. Then ask for a pricing page, a dashboard that looks generic, or a design system for a project that has none.

    /plugin marketplace add rob1-alt/ui-taste
/plugin install ui-taste@ui-taste
    git clone https://github.com/rob1-alt/ui-taste.git
cp -r ui-taste/skills/ui-taste ~/.claude/skills/
